Optical Character Recognition (OCR) reads printed or handwritten text from an image and converts it into editable, searchable plain text — useful for digitizing scanned documents, extracting quotes from screenshots, or pulling text out of photographed notes.

This is a server-backed tool, since OCR models are too large to run efficiently in-browser. Upload an image, and extracted text appears ready to copy — the source image itself is never stored.
