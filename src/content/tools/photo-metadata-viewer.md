Before deciding whether to strip a photo's metadata, it's useful to actually see what's embedded in it. This tool reads and displays the full EXIF data set — camera settings, GPS coordinates if present, timestamp, and software history — without modifying the file.

Upload a photo to inspect its metadata; use the companion Remove Metadata tool if you decide to strip it before sharing.
