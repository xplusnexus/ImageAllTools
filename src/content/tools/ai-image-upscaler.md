Traditional resizing can only stretch existing pixels — enlarging a small image this way quickly looks soft or blocky. An AI upscaler instead uses a trained model to infer plausible new detail, producing a sharper result at 2x or 4x the original resolution.

This is one of the few tools on the platform that processes on a server rather than fully in-browser, since the underlying model is too large to run client-side. Your image is processed and then deleted automatically — see the privacy note on this page for the exact wording.
